4. CRUD de Usuário
4.1 Criar usuário
- POST /users
- Criar usuário no sistema

4.2 Listar usuários
- GET /users
- Paginação
- Acesso restrito (admin)

4.3 Buscar usuário por ID
- GET /users/:id
- Verificar permissão

4.4 Atualizar usuário
- PUT /users/:id
- Atualizar nome, email e senha
- Regerar hash de senha se necessário

4.5 Deletar usuário
- DELETE /users/:id
- Usuário pode excluir a própria conta
- Admin pode excluir qualquer usuário

--------------------------------------------------

5.1 Modelagem de evento
- Criar tabela/model Event
- Campos:
  id
  title
  description
  date
  location
  user_id
  created_at
  updated_at

5.2 Criar evento
- POST /events
- Associar evento ao usuário autenticado

5.3 Listar eventos
- GET /events
- Listar todos ou apenas do usuário
- Filtros por data ou título
- Paginação

5.4 Buscar evento por ID
- GET /events/:id
- Retornar detalhes completos

5.5 Atualizar evento
- PUT /events/:id
- Apenas criador pode editar
- Validar dados

5.6 Deletar evento
- DELETE /events/:id
- Apenas criador ou admin
